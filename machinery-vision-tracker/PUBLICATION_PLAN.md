# Project publication

The project owner authorized publication of custom source code under AGPL-3.0 on October 5, 2026. The repository includes both methods, tests, configuration, supporting scripts, and selected screenshots and plots. Full videos are excluded following the owner's subsequent explicit decision.

Weights, annotation databases, recruitment documents, environments, credentials, and personal paths are excluded. Dependencies retain their licenses; see THIRD_PARTY_NOTICES.md.

Before publication, content and history are reviewed, tests and the publication validator are run. New commits use a project identity without a personal email. Existing public history is not rewritten.
